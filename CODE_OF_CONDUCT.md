# Code of Conduct

Thira follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming, whatever someone's experience, background or identity.
- Critique code and ideas, not people.
- No harassment, insults, sexualized language or imagery, or publishing others' private information.

This applies in all project spaces: issues, pull requests, discussions, and anywhere you represent the project.

## Reporting

If someone's behavior is unacceptable, report it privately to the maintainer, [@SreeshanthT](https://github.com/SreeshanthT), by opening a [private report](https://github.com/SreeshanthT/thira/security/advisories/new) titled "Conduct report". You can also use GitHub's **Report content** option on any comment.

Reports are handled confidentially. The maintainer may remove content, warn, or temporarily or permanently ban anyone who violates this code, following the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant.
